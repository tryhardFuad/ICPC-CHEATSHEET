# ICPC Preliminary Reference Repo

HOW TO USE DURING THE CONTEST
1. Read ALL problems first (10-15 min). Rank them easy -> hard.
2. Open problem_patterns.txt: match constraints + keywords to a technique.
3. Open the matching .cpp file, copy the function, adapt it.
4. Before submitting, go through checklist.txt.

FILE INDEX
template.cpp          Start every solution from this.
problem_patterns.txt  "n <= 1e5 means what?" and "keyword -> technique" tables.
stl_cheatsheet.cpp    Copy-paste STL usage: sort, set, map, heap, unique, etc.
math_quicksheet.txt   Formulas, counting tricks, constructive tricks.
contest_strategy.txt  Team workflow, verdict meanings, debugging steps.
greedy.cpp            Greedy templates (intervals, Kadane, scheduling).
binary_search.cpp     Binary search + binary search on answer.
prefix_sum.cpp        Prefix sums, 2D prefix, difference array.
number_theory.cpp     gcd, modpow, sieve, factorization, nCr mod p.
math_basics.cpp       ceil div, isqrt, base conversion, bit tricks.
checklist.txt         Pre-submit checks.
